# WebChat

Une application de messagerie/discussion construite avec ASP.NET Core et Angular. Le but de ce projet est avant tout pédagogique.

## Fonctionnalités actuelles
- Envoi et réception des messages

## Fonctionnalités futures
- Le serveur conserve uniquement les N derniers messages
- Stocker les messages en base de données
- Reception des messages en temps réel
- Voir quand un utilisateur est en train d'écrire
- Avoir plusieurs conversations possibles publics/privées
- Authentification de l'utilisateur
